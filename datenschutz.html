Privacy policy

Last updated: 23 November 2026

Who uses this app

Goldenegg Studio is a private tool used only by the owner of the YouTube channel Goldenegg. It is not offered to the public.

What data the app uses

When the owner signs in with Google, the app receives an access token for the owner's own YouTube channel. It uses YouTube API Services to:

  • upload the owner's own videos with title, description and tags (videos.insert),
  • read the name of the owner's own channel to show which channel is connected (channels.list).

Where data is stored

The access token and the upload plan (file name, title, planned time, video ID) are stored only on the owner's own computer. Nothing is stored on any server run by this app.

Sharing

No data is sold, shared with third parties or used for advertising.

Google and YouTube

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time on the Google security settings page. The owner can delete the stored token by deleting the file on their computer.

Data retention and deletion

The app keeps the access token only as long as the owner uses the app. When access is revoked, or when the owner stops using the app, the token and the upload plan are deleted from the owner's computer within 7 days. Videos on YouTube can be deleted at any time in YouTube Studio.
